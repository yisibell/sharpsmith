# sharpsmith Documentation / sharpsmith 文档

`sharpsmith` is a `spritesmith` engine powered by `sharp`, compatible with
`spritesmith-engine-spec@2.0.0` and Node.js 22+.

`sharpsmith` 是一个基于 `sharp` 的 `spritesmith` 引擎，兼容
`spritesmith-engine-spec@2.0.0`，支持 Node.js 22 及更高版本。
